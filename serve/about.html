About DVWS

One server, thirteen terrible decisions, and a workshop behind every one of them.

What this is

Damn Vulnerable Web Server is a small, self-contained HTTP server written in C++ with a bundled native CGI helper for executable endpoints. It exists to give security workshops a realistic target: not a puzzle box with one contrived flaw, but a whole little deployment -- static site, blog, downloads area, admin console, logs -- with the kinds of mistakes real teams ship.

How it's built

core
Hand-rolled C++ request loop, no framework, no TLS
cgi helper
Tiny native binary staged per-request from the server bundle
content
Plain HTML/CSS/JS in the docroot
auth
HTTP Basic for the admin area
sessions
Cookie-based, home-grown

Ground rules

Never expose DVWS to a network you care about. It announces itself in every response header and in its status document precisely so scanners and students can find it. If you can compromise it in under an hour, you're ready for the workshop final.
