Projects

Everything this box currently hosts. Small tools, one admin area, and the CGI rules engine that ties them together.

Request echo

Debug endpoint that reports what the server sees on each call: request line, query parameters, headers. Located at /echo.

Open →

Access log viewer

Reads /tmp/server.log and greps it live. The filter parameter is passed to grep so you can use real patterns.

Open →

Status API

JSON document describing the running server: version, docroot, uptime, requests handled. Unauthenticated by design.

Open →

Admin console

Static dashboard behind HTTP Basic auth. System status, file uploads, CGI rule management, logger configuration.

Open →

Whoami

Small authenticated utility that answers with the identity the server believes you have. Useful for debugging auth headers.

Open →

CGI rules engine

Pattern rules under /cgi-bin/ that dispatch to registered handlers. Rules can be added at runtime from the admin console.

Manage rules →

Quick Deploy

Upload a .zip archive to deploy a static site instantly. Extracted to /deploy/ and served immediately. Admin-only feature.
