Debug tools running on this box

Log viewer

Every request the server handles is appended to the access log. Filter it live from the /logs endpoint -- grep-style, straight from disk.

Open /logs →

Request echo

A PHP debug page that reports what the interpreter sees: superglobals, SAPI, PHP version. Handy when wiring up proxies.

Open /echo.php →

Status endpoint

JSON status document with uptime, request count, docroot and interpreter path. Monitors love it.

Open /status →
